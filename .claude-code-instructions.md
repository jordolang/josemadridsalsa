## 🏗️ PROJECT CONTEXT

### Architecture Overview
A comprehensive e-commerce website for Jose Madrid Salsa, featuring product catalog, shopping cart, user accounts, admin panel, and integrated payment processing.

**Technical Stack:**
- **Framework:** Next.js 14+ with App Router
- **Language:** TypeScript
- **Styling:** Tailwind CSS
- **Database:** Prisma with PostgreSQL
- **Authentication:** NextAuth.js
- **Payments:** Stripe
- **Deployment:** Vercel

### Key Features
- Product catalog with variants
- Shopping cart and checkout
- User authentication and accounts
- Admin dashboard
- Recipe management
- Location finder
- Fundraiser management
- AI-powered chatbot
- Stripe payment processing
- Email notifications
