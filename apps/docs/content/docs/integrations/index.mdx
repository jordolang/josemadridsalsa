# Integrations

<PageInlineTOC>Jump to integration</PageInlineTOC>

Most integrations are optional and degrade gracefully when their environment
variables are unset. Credentials for several can be entered in the admin panel
instead of in the environment — those are stored encrypted, and admin-entered values
win over environment ones.
