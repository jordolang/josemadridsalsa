## Buying a gift certificate

Go to [Buy a gift certificate](https://www.josemadridsalsa.com/gift-certificates/purchase), choose an amount, and check out. The recipient gets a code that looks like `JMS-GC-XXXX-XXXX`.

## Checking your balance

Enter your code on the [balance page](https://www.josemadridsalsa.com/gift-certificates/balance).

## Using a gift certificate

1. Add salsa to your cart and go to checkout.
2. Enter your code in the discount / gift certificate field.
3. If the certificate covers the full total, you're done. Otherwise, pay the rest with a **card or Link**.

<Callout type="warn">
While a gift certificate is applied, **PayPal, Venmo, and Cash App Pay aren't available** for that order.
</Callout>

## Common questions

<Accordions>
  <Accordion title="My code says it's invalid">
    Double-check the code for typos. The letter **O** and the number **0** are easy to mix up. Copy and paste it from the email if you can. Still stuck? [Contact us](https://www.josemadridsalsa.com/contact) with the code and we'll check it.
  </Accordion>
  <Accordion title="Can I return a gift certificate?">
    No, gift certificates are non-returnable.
  </Accordion>
</Accordions>
